# Sample audio

Three-minute clips from public Nerdearla talks, used to try Vox Libera without a live stage.
Mono, 16 kHz, Opus. Any format ffmpeg can read works as a sample: drop files here and they show up
in the dashboard's **Simulate** list.

| File | Language | Source |
|---|---|---|
| `talk-en.opus` | English | [Nerdearla talk on YouTube](https://www.youtube.com/watch?v=GVadbxHks_A), from 05:00 to 08:00 |
| `talk-es.opus` | Spanish | [Nerdearla talk on YouTube](https://www.youtube.com/watch?v=EtIQ6CYJIQs), from 05:00 to 08:00 |

All rights to the talks belong to their speakers and Nerdearla. The clips are included only as
test material for this open source project.
